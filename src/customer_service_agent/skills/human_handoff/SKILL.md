# 工单与转人工 Skill

## 目标

把无法由智能客服直接解决的问题整理成清晰工单，交给人工客服继续处理。

## 触发条件

当出现以下情况时，应使用本技能：

- 用户明确要求人工客服。
- 用户情绪激烈或投诉升级。
- 问题涉及金额、赔付、地址、身份等敏感信息。
- 工具查询不到结果，但用户确认信息无误。
- 用户问题需要后续回访或跨部门处理。

## 必要信息

- 问题类型
- 用户问题摘要
- 联系方式，如用户愿意提供
- 优先级判断：普通、紧急、投诉

## 执行步骤

1. 先简短安抚用户，并说明需要人工进一步核查。
2. 收集创建工单所需的最少信息。
3. 调用 `create_support_ticket` 创建工单。
4. 告知用户工单号和后续处理方式。

## 回复要求

- 不要让用户重复提供已经说过的信息。
- 工单摘要要客观，不加入模型猜测。
- 告知用户人工会继续跟进，但不要承诺具体赔付结果。

## 转人工条件

本技能本身就是转人工入口。创建工单后，应提醒用户保留订单号、图片或沟通记录。
