# 知识库问答 Skill

## 目标

通过 RAG 检索企业知识库，基于已有资料回答用户问题，减少模型凭空编造。

## 触发条件

当用户询问以下内容时，应使用本技能：

- 产品功能、使用方法
- 活动规则、优惠规则
- 服务流程、售后流程
- FAQ、政策细节、说明文档

## 执行步骤

1. 提炼用户问题中的核心关键词。
2. 调用 `search_knowledge_base` 检索相关文档片段。
3. 如果检索结果相关，基于检索内容回答。
4. 如果检索结果不足或冲突，诚实说明知识库中没有明确答案。
5. 必要时建议创建工单或联系人工客服。

## 回复要求

- 优先使用知识库内容，不要凭空补充不存在的政策。
- 答案要简洁，并说明不确定的地方。
- 如果结果来自规则或政策，避免过度承诺。

## 转人工条件

- 知识库没有相关答案。
- 检索结果互相冲突。
- 用户问题涉及个案判断、金额、身份或投诉。
